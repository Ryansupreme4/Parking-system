## Parking Management System Algorithm



1\. Start the program.

2\. Initialize 30 parking slots from S01 to S30 as available.

3\. Display the main menu.

4\. If the user chooses Show Slots, display the available and occupied slots.

5\. If Vehicle Entry is selected, check for an available slot.

6\. Enter the vehicle registration number, vehicle type and owner's name.

7\. Check whether the vehicle is already parked.

8\. Assign the first available slot and record the entry time.

9\. Mark the slot as occupied and close the barrier.

10\. If Vehicle Exit/Payment is selected, enter the vehicle registration number.

11\. Find the vehicle and calculate the parking duration.

12\. Calculate the fee at KSh 80 per hour.

13\. If payment is confirmed, release the parking slot and open the barrier.

14\. The user can also view parked vehicles and the system summary.

15\. If Exit is selected, close the program.

16\. Stop.
