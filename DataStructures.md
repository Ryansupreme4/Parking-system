Data Structures

The parking management system uses the following data structures.

1.Array

Arrays are used to store parking slots and vehicle records. The system has 30 parking slots, from S01 to S30.

2.Structure

Structures are used to group related information.

The Vehicle structure contains:
- Registration number
- Vehicle type
- Owner name
- Parking slot
- Entry time
- Parking status

The Parking slot structure contains:
- Slot number
- Occupied status

3.Boolean

Boolean values are used to show whether a vehicle is parked and whether a parking slot is occupied.

4.Integer

Integers are used for the number of vehicles, slot positions and parking duration.

5.Double

A double value is used when calculating the parking fee.
