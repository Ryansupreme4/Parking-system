PARKING MANAGEMENT SYSTEM

INTRODUCTION

This project is a C++ based parking management system designed to help manage vehicles entering and leaving a parking area.

MAIN FEATURES

- 30 parking slots from S01 to S30
- Checks for available parking slots
- Records vehicle registration number
- Records vehicle type
- Records owner's name
- Assigns an available parking slot
- Records vehicle entry time
- Calculates parking duration
- Calculates parking fees at KSh 80 per hour
- Confirms payment before exit
- Releases the parking slot after payment
- Simulates the parking barrier opening and closing
- Displays parked vehicles
- Displays a system summary


DATA STRUCTURES

The program uses arrays and structures to manage parking slots and vehicle information. Boolean, integer and double data types are also used.


HOW THE SYSTEM WORKS

When a vehicle arrives, the system first checks whether a parking slot is available. The vehicle details are then entered and an available slot is assigned.

When the vehicle leaves, the registration number is used to find the vehicle. The system calculates the parking duration and the amount to be paid. After payment is confirmed, the parking slot becomes available again and the barrier opens.


PARKING RATE

The parking rate used by the system is KSh 80 per hour.


HOW TO RUN THE PROGRAM

1. Open the project in Code::Blocks.
2. Open parking system.cpp.
3. Build and run the program.
4. Use the numbered menu to manage vehicle entry, vehicle exit, parking slots and system information.
